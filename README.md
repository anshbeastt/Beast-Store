## ✨ Features

- **Transparent Frosted Navigation:** Sticky navbar with `backdrop-blur` and smooth anchor scrolling (`#hero`, `#products`, `#about`, `#contact`).
- **Curated Highlights Showcase:** Product catalog cards with scent notes, prices, badges, and 1-click WhatsApp order routing.
- **Brand Story & Guarantees:** Clean Burn Guarantee and Phthalate & Toxin-Free artisanal promises.
- **Fully Responsive & Mobile Ready:** Tailored for all screen sizes with animated mobile navigation drawer.
- **Zero Build Configuration Needed:** Pure HTML5, Vanilla CSS, and Tailwind CDN for ultra-fast load times.

## 🚀 Deploying to Vercel

This repository is optimized for instant deployment on [Vercel](https://vercel.com):

1. Go to [Vercel Dashboard](https://vercel.com/new).
2. Import the repository `https://github.com/anshbeastt/Beast-Store`.
3. Keep default settings (Framework Preset: **Other** or **None**).
4. Click **Deploy**! 🚀

## 💻 Running Locally

Simply open `index.html` in any modern browser, or run a local static server:

```bash
# Using npx serve
npx serve .

# Or using Python
python -m http.server 3000
```
